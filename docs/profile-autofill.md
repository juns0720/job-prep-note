# AI로 지원서 인적사항 채우기

채용 사이트 지원서의 이름, 연락처, 학력, 자격증 같은 칸을 AI가 앱의 **인적사항** 탭에 적어 둔 값으로
채워 줍니다. 지원서마다 같은 내용을 다시 입력하지 않아도 됩니다.

AI가 지원서를 열어 보고 입력하려면 [Aside](https://aside.com) 브라우저가 필요합니다.

## 처음 한 번만 준비하기

1. [README의 배포 설정](../README.md#0-준비물)을 마칩니다.
2. [aside.com/download](https://aside.com/download)에서 Aside를 내려받아 설치합니다. macOS 15 이상 또는 Windows에서 쓸 수 있습니다.
3. Aside를 열고 로그인합니다. 계정이 없으면 여기서 만듭니다.
4. Claude Code나 Codex 같은 AI 코딩 도구에서 1단계에서 만든 내 저장소를 열고 이렇게 요청합니다.

```text
docs/ai/profile-autofill.md를 보고 Aside를 연결해 줘.
```

중간에 AI가 Aside에서 승인을 눌러 달라고 하면, Aside의 **Settings → Account → Devices**에서 승인합니다.
연결이 끝나면 AI 도구를 한 번 껐다 켭니다.

## 인적사항 적어 두기

앱의 **인적사항** 탭에 지원서에 자주 나오는 내용을 적습니다. 섹션은 세 가지 모양 중에서 고릅니다.

| 모양 | 이럴 때 | 예시 |
|---|---|---|
| 항목 | 항목과 값을 한 줄씩 적을 때 | 기본 인적사항, 주소, 병역 |
| 여러 건 | 같은 칸으로 여러 개를 적을 때 | 학력, 자격증, 수상 |
| 긴 글 | 긴 글 하나를 적을 때 | 경력기술서 |

- 섹션마다 있는 **입력 규칙** 칸에 "영문 이름은 성-이름 순서로" 같은 요령을 적어 두면 AI가 그대로 따릅니다.
- 증명사진과 서류 파일은 **첨부 파일·링크**에 올립니다.
- 주민등록번호, 비밀번호, 계좌번호는 적지 않습니다. AI도 이런 칸은 채우지 않습니다.

다른 곳에 정리해 둔 인적사항이 있다면 AI에게 옮겨 달라고 해도 됩니다.

```text
이 내용을 내 앱의 인적사항 탭에 넣어 줘.
(정리해 둔 내용을 붙여 넣습니다)
```

## 지원서 채우기

1. Aside에서 채용 사이트에 로그인하고 지원서 작성 화면을 열어 둡니다.
2. AI 코딩 도구에서 내 저장소를 열고 요청합니다.

```text
Aside에 열어 둔 OO기업 지원서의 인적사항을 채워 줘.
docs/ai/profile-autofill.md의 절차를 따라 줘.
지원 직무는 백엔드 개발, 근무지는 서울이야.
```

지원 직무, 근무지, 지망 순위처럼 지원할 때마다 달라지는 내용은 요청에 같이 적습니다.
AI가 입력하는 동안에는 Aside 창을 닫거나 다른 페이지로 옮기지 않습니다.

## 끝나면 확인할 것

AI가 세 가지로 나눠 알려 줍니다.

1. **채운 칸** — 넣은 칸과, 양식에 맞춰 바꾼 값
2. **못 채운 칸** — 인적사항에 값이 없어 비워 둔 칸
3. **직접 할 칸** — 주민등록번호, 본인 인증처럼 직접 해야 하는 것

못 채운 칸은 인적사항 탭에 빈 칸으로 생깁니다. 빨간 `미기록`으로 보이니, 값을 채워 두면 다음 지원서부터는
자동으로 들어갑니다.

AI는 임시저장까지만 누릅니다. 지원서를 한 번 훑어본 뒤 **최종 제출은 직접 합니다.**

## 잘 안 될 때

| 이런 경우 | 이렇게 해 보세요 |
|---|---|
| AI가 Aside를 찾지 못한다고 함 | "처음 한 번만 준비하기"의 4번 요청을 다시 하고, AI 도구를 껐다 켭니다 |
| AI가 브라우저 창이 없다고 함 | Aside에서 새 창을 열고 지원서 페이지를 다시 엽니다 |
| 로그인이 필요하다고 함 | 채용 사이트에 직접 로그인한 뒤 다시 요청합니다 |
| 사진이나 파일이 안 올라감 | 그 칸은 직접 올리고, AI에게 나머지를 이어서 채워 달라고 합니다 |
