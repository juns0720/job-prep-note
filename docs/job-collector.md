# AI로 공고 수집하기

AI 코딩 도구에 원하는 조건을 알려 주고, 공고를 수집해 앱에 넣어 달라고 요청합니다.
수집 대상은 사람인, 자소설닷컴, 인디스워크입니다.

## 처음 사용하기

1. [README의 배포 설정](../README.md#0-준비물)을 완료합니다.
2. Claude Code나 Codex 같은 AI 코딩 도구에서 [README 1단계](../README.md#1-내-저장소-만들기)의 저장소를 엽니다.
3. 아래처럼 수집을 요청합니다.

```text
백엔드 신입 공고를 수집해서 내 앱에 넣어 줘.

조건:
- 근무 지역: 서울, 경기
- 경력: 신입, 채용연계형 인턴
- 기술 스택: Java, Spring

scripts/의 기존 수집 도구를 사용해 줘.
실행 환경과 수집 설정, 앱의 필터링 규칙도 이 조건에 맞게 준비해 줘.
자소서 문항과 전형 조건이 있으면 함께 가져오고, 이미 저장한 공고는 그대로 둬.
끝나면 새로 추가한 공고 수와 수집하지 못한 사이트를 알려 줘.
필요한 접속 정보가 없으면 어떤 값이 필요한지 알려 줘.
```

예시의 지역, 경력, 기술 스택을 원하는 조건으로 바꿔 요청하세요.
처음 설정할 때는 README 5단계의 Supabase 접속값과 4단계에서 만든 앱 로그인 이메일, 비밀번호가 필요합니다. AI가 이 값을 요청하면 안내에 따라 설정합니다.

## 다시 수집하기

같은 조건으로 새 공고를 수집하려면 아래처럼 요청합니다.

```text
지난번과 같은 조건으로 새 공고를 수집해서 앱에 넣어 줘.
```

조건을 바꾸거나 사이트를 지정할 수도 있습니다.

```text
이번에는 지역 제한 없이 Python, Go 백엔드 신입 공고를 찾아 줘.
자소설닷컴과 인디스워크에서 수집해서 앱에 넣어 줘.
```

## 앱에서 확인하기

수집이 끝나면 배포된 앱을 새로고침하고 **공고** 탭을 엽니다.

- 지원할 공고는 **자기소개서에 추가**를 누릅니다.
- 관심 없는 공고는 **삭제**를 누릅니다.
- 옮긴 공고는 **옮김**, 삭제한 공고는 **지움**에서 확인합니다. 다시 검토하려면 **대기로 되돌리기**를 누릅니다.

**공고 열기**를 눌러 원문의 지원 조건과 마감일을 확인하세요.

## 원하는 결과가 나오지 않을 때

AI에게 결과와 수정할 조건을 함께 알려 주세요.

```text
공고가 너무 적어. 제외된 이유를 확인하고 기술 스택 조건을 풀어서 다시 수집해 줘.
```

```text
수집했다고 하는데 앱에 보이지 않아. 앱에 가져오기까지 완료했는지 확인해 줘.
```

수집하지 못한 사이트의 공고는 해당 사이트에서 직접 확인합니다.
