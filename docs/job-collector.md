# AI로 공고 수집하기

AI 코딩 도구에 원하는 조건을 알려 주면 수집 설정, 공고 수집, 앱에 가져오기까지 맡길 수 있습니다.
사람인, 자소설닷컴, 인디스워크를 지원합니다.

## 처음 사용하기

1. [README의 배포 설정](../README.md#0-준비물)을 완료합니다.
2. Claude Code나 Codex 같은 AI 코딩 도구에서 README 1단계에서 만든 내 저장소를 엽니다.
3. 아래처럼 수집을 요청합니다.

```text
백엔드 신입 공고를 수집해서 내 앱에 넣어 줘.

조건:
- 근무 지역: 서울, 경기
- 경력: 신입, 채용연계형 인턴
- 기술 스택: Java, Spring

scripts/의 기존 수집 도구를 사용해 줘.
실행 환경과 수집 설정, 앱의 필터링 규칙도 이 조건에 맞게 준비해 줘.
자소서 문항과 전형 조건이 있으면 함께 가져오고, 이미 저장한 공고는 그대로 둬.
끝나면 새로 추가한 공고 수와 수집하지 못한 사이트를 알려 줘.
필요한 접속 정보가 없으면 어떤 값이 필요한지 알려 줘.
```

지역, 경력, 기술 스택은 본인이 원하는 조건으로 바꾸면 됩니다.
처음에는 AI가 연결에 필요한 값을 물어봅니다. README 5단계의 Supabase 접속값과 4단계의 앱 로그인 이메일·비밀번호를 알려 주면 됩니다.

## 다음부터는

같은 조건으로 수집하려면 짧게 요청하면 됩니다.

```text
지난번과 같은 조건으로 새 공고를 수집해서 앱에 넣어 줘.
```

조건을 바꾸거나 사이트를 지정할 수도 있습니다.

```text
이번에는 지역 제한 없이 Python, Go 백엔드 신입 공고를 찾아 줘.
자소설닷컴과 인디스워크에서 수집해서 앱에 넣어 줘.
```

## 앱에서 확인하기

수집이 끝나면 배포된 앱을 새로고침하고 **공고** 탭을 엽니다.

- 지원할 공고는 **자기소개서에 추가**를 누릅니다.
- 관심 없는 공고는 **삭제**를 누릅니다.
- 옮기거나 삭제한 공고는 **옮김**, **지움**에서 다시 확인합니다. **대기로 되돌리기**도 가능합니다.

지원 조건과 마감일은 **공고 열기**로 원문을 확인하세요.

## 원하는 결과가 나오지 않을 때

AI에게 결과와 수정할 조건을 함께 알려 주세요.

```text
공고가 너무 적어. 제외된 이유를 확인하고 기술 스택 조건을 풀어서 다시 수집해 줘.
```

```text
수집했다고 하는데 앱에 보이지 않아. 앱에 가져오기까지 완료했는지 확인해 줘.
```

사이트에서 정보를 가져오지 못한 경우에는 해당 사이트의 공고를 직접 확인합니다.
