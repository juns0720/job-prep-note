# 공고 수집 가이드

사람인, 자소설닷컴, 인디스워크의 공고를 수집해 앱에 가져옵니다.
[README의 0~6단계](../README.md#0-준비물)를 마친 뒤 프로젝트 폴더에서 진행하세요.

## 1. 처음 설정하기

설정 파일을 만듭니다.

```bash
cp scripts/sources.example.json scripts/sources.json
```

`scripts/sources.json`의 예시는 백엔드 신입 기준입니다. 원하는 검색 조건으로 수정합니다.

| 설정 | 입력할 값 |
|---|---|
| `regions` | 원하는 근무 지역. 예: `["서울", "경기"]`. 전국이면 `[]` |
| `targets` | 수집할 사이트별 설정. 아래 예시 참고 |
| `enabled` | 해당 사이트를 제외하려면 `false` |

지역 정보가 없는 공고도 수집되므로 지원 전에 근무지를 확인하세요.

`.env.local`에 앱 로그인 계정을 입력합니다. 비워 두면 실행할 때 터미널에서 입력합니다.

```dotenv
STUDY_NOTE_EMAIL=앱에 로그인하는 이메일
STUDY_NOTE_PASSWORD=앱에 로그인하는 비밀번호
```

앱의 **공고 → 필터링 규칙**에서 원하는 직무, 경력, 스택을 선택합니다.
조건을 선택하지 않은 항목은 제한 없이 수집합니다.

### 사람인

사람인에서 검색어, 경력, 지역을 선택한 뒤 검색 결과 주소를 `url`에 넣습니다.
`pages`는 수집할 페이지 수입니다(최대 10).

```json
{
  "site": "saramin",
  "label": "백엔드 신입",
  "url": "https://www.saramin.co.kr/zf_user/search?searchType=search&searchword=백엔드&exp_cd=1",
  "pages": 2
}
```

### 자소설닷컴

`months`에 수집할 개월 수, `dutyGroups`에 직무 코드를 입력합니다.

```json
{
  "site": "jasoseol",
  "label": "개발 공채",
  "months": 2,
  "dutyGroups": [162, 165, 170]
}
```

| 코드 | 직무 | 코드 | 직무 |
|---|---|---|---|
| 160 | QA | 166 | 네트워크, 보안, 운영 |
| 161 | 앱개발 | 167 | 빅데이터, AI |
| 162 | 웹개발 | 168 | 게임개발 |
| 163 | 데이터엔지니어, 분석, DBA | 169 | HW, 임베디드 |
| 164 | 시스템프로그래머 | 170 | SW, 솔루션, ERP |
| 165 | 응용프로그래머 | 171 | 서비스기획, PM |

### 인디스워크

`tag`와 `categories`에 사이트에 표시된 직무와 경력 분류를 입력합니다.
`pages`는 수집할 페이지 수입니다.

```json
{
  "site": "inthiswork",
  "label": "개발 신입/인턴",
  "tag": "IT개발",
  "categories": ["신입/인턴"],
  "pages": 2
}
```

### 공고 주소 직접 입력하기

다른 사이트의 공고는 `manual` 항목의 `urls`에 입력하고 `enabled`를 `true`로 바꿉니다.

```json
{
  "site": "manual",
  "label": "직접 모은 공고",
  "enabled": true,
  "urls": ["https://www.wanted.co.kr/wd/123456"]
}
```

## 2. 공고 수집하기

```bash
node scripts/collect.mjs
```

실행이 끝나면 결과 파일 경로가 표시됩니다. 다음 단계의 `<날짜>`를 해당 파일의 날짜로 바꿔 주세요.

이미 수집한 기간까지 다시 확인하려면 `--all`, 특정 사이트만 수집하려면 `--only`를 사용합니다.

```bash
node scripts/collect.mjs --all
node scripts/collect.mjs --only jasoseol
```

## 3. 상세 정보 추가하기 (선택)

자소서 문항과 전형 조건 등 상세 정보가 필요하면 실행합니다. 필요 없다면 4단계로 넘어갑니다.

```bash
node scripts/enrich.mjs scripts/out/postings-<날짜>.json
```

### 잡플래닛 회사 평판 추가하기 (선택)

1. 브라우저에서 잡플래닛에 로그인합니다.
2. 개발자도구의 **Network**에서 잡플래닛 요청을 선택합니다.
3. **Request Headers → Cookie** 값을 복사해 `.env.local`에 입력합니다.

```dotenv
JOBPLANET_COOKIE=복사한 값
```

설정 후 상세 정보 추가 명령을 실행합니다. 쿠키가 만료되면 다시 복사합니다.
설정하지 않아도 다른 상세 정보는 가져올 수 있습니다.
평판이 표시되지 않는 회사는 앱의 잡플래닛 검색 링크로 확인합니다.

## 4. 앱에 가져오기

```bash
node scripts/import.mjs scripts/out/postings-<날짜>.json
```

앱을 새로고침하고 **공고** 탭에서 확인합니다. 이미 저장한 공고는 건너뜁니다.

- 지원할 공고는 **자기소개서에 추가**를 누릅니다.
- 관심 없는 공고는 **삭제**를 누릅니다.
- 다시 확인하려면 **옮김** 또는 **지움**에서 공고를 선택합니다. **대기로 되돌리기**도 가능합니다.

## 문제 해결

| 증상 | 해결 방법 |
|---|---|
| `sources.json 이 없다` | 1단계의 설정 파일 복사 명령을 실행합니다 |
| 로그인 실패 | `.env.local`의 이메일과 비밀번호가 앱 로그인 계정과 같은지 확인합니다 |
| 수집한 공고가 너무 적음 | 앱의 필터링 조건을 줄이고 `--all`로 다시 수집합니다. 결과 파일의 `excluded`에서 제외 사유를 확인할 수 있습니다 |
| 수집 결과가 0건 | 검색 조건을 확인하고 사이트별로 `--only`를 실행합니다. 사이트 구조가 바뀌면 수집이 실패할 수 있습니다 |
| 앱에 공고가 보이지 않음 | 4단계를 실행했는지 확인하고 앱을 새로고침합니다. **옮김**과 **지움** 목록도 확인합니다 |

공고에 직무, 경력, 스택 정보가 없으면 선택한 조건과 다른 공고가 포함될 수 있습니다.
지원 조건과 마감일은 원문 공고에서 확인하세요. 수집은 개인 용도로 하루 한두 번 정도 실행해 주세요.
